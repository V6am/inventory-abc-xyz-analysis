# ABC/XYZ-анализ и выявление неликвидов для оптимизации запасов

Проект по анализу товарных запасов на основе датасета **DataCo SMART SUPPLY CHAIN** с применением ABC/XYZ-анализа и анализа оборачиваемости для выявления неликвидных позиций.

## Цель проекта

Категоризировать товарный ассортимент по степени влияния на выручку и стабильности спроса, а также определить долю неликвидных и рисковых товаров для выработки рекомендаций по управлению складскими запасами.

## Методология

Анализ проведен в два этапа с использованием Excel и Power Query:

### Этап 1: ABC/XYZ-анализ
*   **ABC-классификация:** Распределение товаров по доле в общей выручке:
    *   **Группа A** (80% выручки) — наиболее ценные товары.
    *   **Группа B** (15% выручки) — товары средней важности.
    *   **Группа C** (5% выручки) — наименее ценные товары.
*   **XYZ-классификация:** Распределение по стабильности спроса на основе коэффициента вариации (CV):
    *   **Группа X** (CV ? 0.1) — стабильный, легко прогнозируемый спрос.
    *   **Группа Y** (0.1 < CV ? 0.25) — колеблющийся спрос.
    *   **Группа Z** (CV > 0.25) — нестабильный, хаотичный спрос.

### Этап 2: Анализ оборачиваемости и неликвидов
*   Расчет дней с момента последней продажи (поле `Shipping Date Clean`) относительно максимальной даты в датасете (26.11.2018).
*   Классификация на четыре категории:
    *   **Неликвид:** > 365 дней с последней отгрузки.
    *   **Риск неликвида:** 180–365 дней.
    *   **Медленно оборачиваемый:** 90–180 дней.
    *   **Активный:** < 90 дней.

## Ключевые результаты и выводы

### 1. ABC/XYZ-анализ: Высокая непредсказуемость спроса
*   **83%** всего ассортимента (95 из 115 товаров) попали в категорию **Z**.
*   Это указывает на невозможность использования классических методов прогнозирования. Необходим переход к динамическому управлению запасами (DDMRP или JIT для отдельных групп).
*   **Группа AZ (7 лидеров продаж):** Нестабильный спрос при высокой доле в выручке. Рекомендуется страховой запас (1.5? от среднемесячных продаж) и еженедельный мониторинг остатков.
*   **Группа CZ (87 товаров):** Мелкие товары с хаотичным спросом. Основные кандидаты на вывод из ассортимента или перевод под заказ.

### 2. Оборачиваемость: Критический уровень неликвидов
*   **96.2%** товаров не отгружались более 180 дней.
*   **Неликвидов (>1 года):** **110 из 177 товаров (62%)**.
*   **В группе риска (6–12 мес):** **61 товар (34%)**.
*   **Активных продаж (<90 дн):** Всего **5 товаров (2.8%)**.
*   **Критический вывод:** Практически весь ассортиментный портфель является неликвидным.
*   **Важное замечание:** Среди неликвидных позиций обнаружены лидеры по выручке (7 товаров группы A). Это аномалия, которая может быть следствием:
    *   Искусственного или устаревшего датасета.
    *   Ошибки в данных по последним отгрузкам.
    *   Завершения жизненного цикла товаров (например, модели прошлых лет).

## Возможные бизнес-решения

На основе анализа можно предложить следующие шаги:
1.  **Ревизия данных:** Перепроверить наличие актуальных транзакций за последний период, так как доля неликвидов подозрительно высока для действующего бизнеса.
2.  **Сокращение ассортимента:** Провести немедленную распродажу или списание 110 товаров из категории «Неликвид».
3.  **Работа с группой CZ:** Для 87 товаров с нестабильным и дешевым спросом пересмотреть целесообразность их постоянного наличия на складе. Возможен переход на модель dropshipping или закупку под конкретный заказ.
4.  **Страховой запас для AZ:** Обеспечить складской резерв для 7 ключевых товаров с непредсказуемым спросом, чтобы не упустить выручку.
